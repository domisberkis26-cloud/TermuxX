FAQ

Is Termux free?

Yes. Termux is free and open-source software.

Can I use this on iPhone?

The original Termux application is Android-only. iPhone users can explore iSH as an alternative.

Does this install all packages automatically?

No. The website provides installation commands. You must first install the terminal application. The commands then install your selected packages.

Can I install my own tools?

Yes. You can customize your package list and create your own installer script.
